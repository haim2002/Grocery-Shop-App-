> [!IMPORTANT]
> ### 🎯 Core Vision & Mission
>
> 1. **Zero Backtracking:** Automatically map and sort item entries into physical supermarket departments (Produce, Bakery, Dairy, Meat, Frozen) to guide users seamlessly from store entrance to checkout.
> 2. **Instant Household Convergence:** Real-time multi-device database mirroring so updates made by one family member at home reflect instantly on the shopper's phone in the store.
> 3. **Single-Handed In-Store UX:** Designed specifically for fast, effortless interaction with low cognitive load during busy trips.

---

## ⚡ Key Highlights (v1.0 Release)

- 🔑 **Google Identity Services:** Secure, one-tap authentication via Firebase Auth and Google Sign-In.
- ⚡ **Zero-Latency Database Sync:** Powered by Firebase Realtime Database with offline persistent caching.
- 🤖 **Automated Department Classification:** Dynamic grouping logic that places items into categorized store departments.
- 🔍 **Localized Fuzzy Autocomplete:** Ultra-fast local product query suggestions.
- 🎨 **Material Design 3 & Dark Mode:** Modern UI implementing adaptive themes and crisp visual hierarchy.

## 🏗️ System Architecture & Tech Stack

SmartCart follows **Modern Android Application Architecture** guidelines, employing **Clean Architecture** principles and the **MVVM (Model-View-ViewModel)** design pattern.
